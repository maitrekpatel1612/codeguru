A beautiful, modern LeetCode practice problem tracker with visual progress tracking. Track your coding journey across 629 problems
with an interactive circular progress ring, difficulty-based color segments, and automatic local storage - no login required.

## Features

- 📊 Interactive circular progress ring with difficulty-based color segments
- 💾 Automatic local storage - all progress saved in your browser
- 🎨 Modern dark theme with smooth animations
- 📱 Fully responsive design for all devices
- 🎲 Smart problem randomization on each load
- 🔗 Direct links to 629 LeetCode problems (87 Easy, 399 Medium, 143 Hard)
- 🔍 Global search functionality with real-time filtering and text highlighting
- 🎯 Filter problems by status (All, Solved, Unsolved) for each difficulty level
- 📈 Toggle between count and percentage view by clicking the progress ring
